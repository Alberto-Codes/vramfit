The stock quantizer's own output for the three refusals the
ADR-0032 note describes.

build: 10362 (4801e3c56)
toolchain hashes: real-row-widths-toolchain-sha256.txt
probe: the real-row-width fixture, with the attention groups
       dropped, then with the embedding assignment replaced by
       nominal 4 and by nominal 2

This file substitutes two roots and changes nothing else.
<toolchain> replaces the stock llama.cpp build directory. <tmp>
replaces the probe's temporary directory. Every argument, exit
code, tensor line, and message reads as the session produced it.

Each section wraps the quantizer in a shell script. The script
appends the argv, the tool's complete merged output, and the exit
code to a log, then runs the pinned binary and exits with its code.
